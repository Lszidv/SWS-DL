# SWS-DL

[English](./README.md) | 简体中文

SWS-DL 是一款用于剪切波分裂分析的 Windows 桌面软件，提供波形预处理、偏振分析、质点运动对比、结果导出和台站统计等功能。

## 下载

请前往 [Releases 页面](../../releases/latest) 下载最新的 Windows 软件包。

完整解压后双击 `SWS-DL.exe` 启动软件。请勿删除或移动同目录下的 `_internal` 文件夹。

## 数据要求

SWS-DL 读取同一事件的三分量 SAC 波形：

- 垂直分量：`V` 或 `Z`
- 东西分量：`E`
- 南北分量：`N`

三个文件应位于同一目录并具有相同前缀，例如：

```text
event01.V.SAC
event01.E.SAC
event01.N.SAC
```

若无法自动识别，软件会提示手动选择各分量文件。

## 分析流程

1. 点击“加载 SAC 文件”，选择三分量中的任意文件。
2. 根据需要进行滤波、去均值或去线性趋势。
3. 设置分析窗口的起止点并检查所选波形区间。
4. 自动搜索或手动设置快波偏振方向 `φ`，检查后点击“确定”。
5. 自动测量或手动设置延迟时间 `δt`，然后点击“应用校正”。
6. 检查五分量波形及校正前后的质点运动图。
7. 导出分析结果。

> 自动搜索和自动测量仅用于辅助判断。最终结果应结合波形、质点运动形态及研究经验进行人工复核。

## 结果输出

结果默认保存在软件目录下：

```text
results/
├── sws_results.csv
└── 台站名/
    ├── 事件结果.txt
    └── 事件结果.json
```

请勿修改 JSON 字段结构，以免影响台站统计功能。

## 台站统计

- 选择 `results` 根目录：查看各台站平均结果和快波偏振玫瑰图。
- 选择台站子目录：查看该台站各事件的事件名、`φ`、`δt` 和质量等级。
- 支持质量等级筛选、保存玫瑰图和导出统计结果。

## 常见问题

- **软件无法启动：** 确认软件包已完整解压，且 `_internal` 与 `SWS-DL.exe` 位于同一目录。
- **三分量识别失败：** 检查文件目录和命名，或按照提示手动选择。
- **无法导出结果：** 需先确认快波方向并完成延迟时间校正。
- **台站统计为空：** 确认所选目录包含 SWS-DL 导出的 JSON 文件。

**运行环境：** Windows 64 位
